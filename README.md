# Pizza Ordering System

A console-based Java application that allows users to create and manage pizza orders through an interactive command-line menu.

This project was originally developed as part of my Java coursework and demonstrates foundational object-oriented programming concepts using multiple interacting classes.

## Features

- Create custom pizza orders
- Choose small, medium, or large pizza sizes
- Add toppings to custom pizzas
- Select preset specialty pizzas
- View individual pizza prices
- Manage multiple pizzas in one order
- Calculate subtotal and sales tax
- Generate an order receipt
- Validate menu selections
- Limit orders to a maximum of 20 pizzas

## Specialty Pizzas

### Meat Lovers Pizza

A preset large pizza with:

- Pepperoni
- Sausage

### Veggie Lovers Pizza

A preset large pizza with:

- Onions
- Peppers
